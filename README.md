# Pulse — Telegram CRM

Локальная админка Telegram-бота для базы клиентов, тегов и моментальных или отложенных рассылок.

## Что уже работает

- сохранение клиента после `/start`;
- запрос номера телефона и email;
- карточки клиентов и назначение тегов;
- сегментация по тегам и исключение тегов;
- немедленные и запланированные рассылки;
- статусы отправки и учёт ошибок;
- демонстрационные записи, которые удаляются одной кнопкой.

## Локальный запуск

Требуется Node.js 22 или новее.

1. Установите зависимости: `npm install`
2. Скопируйте `.env.example` в `.dev.vars`
3. Вставьте токен из BotFather в `TELEGRAM_BOT_TOKEN`
4. Запустите админку: `npm run dev`
5. Откройте адрес, показанный в терминале
6. Во втором терминале запустите бота: `npm run bot`

Если админка открылась не на `http://localhost:3001`, укажите фактический адрес в `LOCAL_APP_URL`.

Секреты из `.dev.vars` исключены из Git и не попадут в GitHub.

## Публикация

GitHub хранит исходный код, но для работающей базы, Telegram webhook и планировщика нужен хостинг приложения. Проект подготовлен к такой публикации; токен бота должен храниться в секретах хостинга, а не в репозитории.
